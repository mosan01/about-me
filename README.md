こんにちは！このサイトは自己紹介用に作成しました。 私はゲームが好きでその中でも最近特にVALORANTというゲームにはまっており今回はVALORANT風に仕上げました。


# 課題の紹介

## TOP

- **タイピングエフェクトで動く自己紹介文**: "I am a プログラマー" → "I am a ゲーマー" → "I am a 音楽愛好家" のように、文字が一文字ずつタイピングされながら自動で切り替わるアニメーションを作りました。文字を配列に入れて時間差で表示・削除する仕組みです。

- **数字がカウントアップする統計ダッシュボード**: 「プログラミング経験2年+」「年間アニメ視聴30作品+」などの数字が0から目標値まで徐々に増えていくアニメーションを作りました。進捗バーも連動して伸びるようにして、それぞれ違う色のグラデーションで見た目も工夫しています。

- **マウスに反応する3Dナビゲーションカード**: 各ページへのリンクカードにマウスを乗せると、カードがマウスの位置に合わせて立体的に回転します。実際に触ってみると面白いです！

- **マウスを追いかける光る円**: VALORANTっぽさを出すために、マウスカーソルの後をピンク色の光る円が追いかける機能を追加しました。スマホでは邪魔になるので自動で非表示になります。

- **参考にしたデザイン**: VALORANTのゲーム画面とか公式サイトを見まくって、あの近未来的でかっこいい感じを真似しました。黒を基調として、赤（#ff4655）と青（#00d4ff）のネオンカラーをアクセントに使用。特にエージェント選択画面のカードデザインやグラデーション効果を参考にして、同じような雰囲気を出せるように頑張りました。

## 自己紹介のページ (About Me)

- **プロフィール情報の見やすい表示**: 名前、年齢、所属、趣味などの基本情報をカード形式で整理して表示しました。背景にはVALORANTのエージェント選択画面を参考にした光る境界線エフェクトを追加。
- **スキルレベルの視覚化**: プログラミング言語（HTML、CSS、JavaScript、Python）のスキルレベルを進捗バーで表現。アニメーション付きで表示されるので見ていて楽しいです。
- **学習履歴のタイムライン**: プログラミングを始めてから現在までの学習過程を年表形式で紹介。各段階での成長ポイントも記載しています。

## お問い合わせ (Contact)

- **入力チェック機能付きフォーム**: メールアドレスの形式チェック、必須項目の入力確認など、間違いがあったらすぐにエラー表示される機能を作りました。

## ゲームページ (Games)

- **スライドショー機能**: VALORANT、Apex Legends、Fortniteの三つのゲームを自動で切り替え表示。左右の矢印キーでの手動操作にも対応しています。
- **色分けとテーマ統一**: VALORANTは赤、Apexはオレンジ、Fortniteは青でそれぞれ色分けし、各ゲームの世界観を表現しました。

## 趣味ページ (Hobby)

- **三つのカテゴリー**: プログラミング、アニメ、音楽の趣味をそれぞれ異なる色とアイコンで表現。統計データも含めて紹介しています。
- **詳細な統計情報**: 年間アニメ視聴数、プログラミング学習時間など具体的な数値で趣味の深さをアピール。

## 音楽ページ (Music)

- **楽曲カードデザイン**: アルバムジャケット風のデザインで各楽曲を表示。クリックすると動画が再生されます。

# 力を入れた点

## 実装面

- **動きのあるアニメーション**: タイピング効果やカウンター、カードの回転など、いろんな動きを作りました。
- **スマホ対応**: パソコン、タブレット、スマホすべてで見やすくなるように調整しました。特にスマホでは操作しやすいよう、ボタンを大きくしたりレイアウトを変更しています。
- **表示速度の改善**: 画像を軽くしたり、重い処理を減らしたりして、サイトがサクサク動くように気を付けました。
- **難しかった部分**: カードの回転の計算が複雑で、何度も調整が必要でした。YouTubeの動画埋め込みも思ったより大変でした。

## デザイン面

- **VALORANTの雰囲気作り**: ゲーム画面を何度も見て、フォントや色、レイアウトまで雰囲気を真似して作りました。
- **色の統一**: 赤と青を基調にして全ページで統一感を出しました。ページごとに少し色を変えつつも、全体はまとまって見えるようにしています。
- **細かい動きの演出**: ボタンにマウスを乗せたときの効果や、カードが浮く演出など、操作していて楽しくなるような細かい動きをたくさん入れました。
- **難しかった部分**: VALORANTっぽさを出しながらも、文字が読みやすく使いやすいサイトにするのが大変でした。アニメーションと見やすさのバランス調整に苦労しました。
